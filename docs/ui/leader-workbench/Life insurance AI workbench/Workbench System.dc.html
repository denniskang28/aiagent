06

Responsive behaviour

1440 × 1024 (design)
240px sidebar, 32px gutters, content max 1360px. Attention cards 3-up, widgets 4-up.
1280
All grids use minmax(0,1fr) so cards compress, not overflow. Table columns keep agent name min 140px; Agent 360 aside stays 1/3.
Below 1280 / mobile (later)
Sidebar collapses to icons/numbers; side panels become bottom sheets. Mobile scope: nudges, quick approvals, agent lookup, coaching notes.

Bilingual text: components never fix widths on labels; Chinese strings run ~40% shorter, English ~1.6× longer — buttons wrap as a group (flex-wrap + gap), headings use text-wrap: pretty.
